# Recurron

A React single-page application with TanStack Router, React Query, and Tailwind CSS,
managed with pnpm and Turborepo. The backend will run separately.

## Development

Use Node.js 22.12 or newer and pnpm 11.24.0.

```sh
pnpm install
pnpm dev
```

Open http://localhost:3000. No backend connection is required for the starting page.

## Structure

```text
apps/web/
  index.html                  HTML entry point
  src/main.tsx                React mount and providers
  src/router.tsx              Router and browser QueryClient
  src/routes/                 File-based pages
  src/routeTree.gen.ts         Generated by the Router plugin; do not edit
  src/styles.css              App styles and Tailwind entry
  vite.config.ts              Router, React, and Tailwind plugins
packages/
  typescript-config/          Shared strict TypeScript settings
  tailwind-config/            Shared Tailwind theme
pnpm-workspace.yaml           Workspace packages and dependency catalog
turbo.json                    Development, build, and typecheck tasks
```

Add pages in `apps/web/src/routes`. Keep application code in web until another
application needs to share it.

## Build and deploy

```sh
pnpm build
pnpm typecheck
pnpm preview
```

The build produces static files in `apps/web/dist`. React renders the UI in the
browser. There is no SSR server, server function, or backend bundled with the app.

Deploy that directory to a static host. Configure the host to serve `index.html`
for application routes so direct links and browser refreshes work. Serve existing
assets normally. `pnpm preview` is for checking the build locally, not production hosting.

For CI, run `pnpm install --frozen-lockfile`, then build and typecheck.
